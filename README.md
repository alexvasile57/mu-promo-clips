Competition MU

Season 6, Episode 19. Grand Opening.

Competition MU is a hard custom MU Online server. Levelling is fast, but master levels are slow, and the drops are generous enough that loot is worth chasing. It's not built for people who want everything handed to them.

Website: competitionmu.com

Server rates
	
Experience	10x
Master experience	1x
Drop rate	30%
Type	Hard custom

You reach the late game quickly with 10x experience, then the 1x master experience makes the rest a real grind. That gap is what the server is about.
